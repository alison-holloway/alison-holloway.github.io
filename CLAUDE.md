## Project Overview

Jekyll-based professional portfolio website for a senior technical writer, hosted on GitHub Pages at alison-holloway.github.io.

## Common Commands

```bash
# Install dependencies
bundle install

# Start local development server (http://localhost:4000)
bundle exec jekyll serve

# Clear build cache if needed
bundle exec jekyll clean

# Re-export Excalidraw diagrams to SVG (after editing .excalidraw files)
npm run export-svg
```

## Architecture

### Jekyll Collections

Portfolio items are managed as a Jekyll collection in `_portfolio/`. Each `.md` file generates a page at `/portfolio/:title/`.

### Layout Hierarchy

- `_layouts/default.html` - Base layout with header, nav, footer
- `_layouts/portfolio_item.html` - Portfolio detail pages with metadata display

### Key Files

| File | Purpose |
|------|---------|
| `_config.yml` | Site config, author info, collection definitions |
| `portfolio/index.html` | Portfolio listing organized into sections using Jekyll server-side rendering |
| `index.html` | Home page for AI consulting and technical writing services |
| `assets/css/main.css` | Full stylesheet with CSS variables and dark mode support |
| `assets/excalidraw/*.excalidraw` | Excalidraw diagram source files (edit in VS Code with Excalidraw extension) |
| `assets/excalidraw/*.svg` | Exported SVG diagrams (generated by `npm run export-svg`) |
| `assets/js/reveal.js` | Scroll reveals for block-level content on every page (selector list at the top) |
| `assets/js/hero-terminal.js` | Animated terminal in the home page hero (scenarios defined at the top) |
| `assets/js/editing-replay.js` | "Watch a draft become documentation" replay on the What I do page (draft and edits defined at the top) |
| `assets/js/audience-switcher.js` | "One idea, four readers" tabs on the What I do page (panel content is HTML in `services.md`) |
| `_data/excerpts.yml` | Annotated excerpts ("Inside the Guide") for portfolio item pages, keyed by file name; rendered by `_includes/annotated-excerpt.html`, behaviour in `assets/js/annotated-excerpt.js` |
| `assets/js/diagrams.js` | Inlines Excalidraw SVGs for draw-on animation; powers the journey explorer (`data-journey-explorer`) on the IA page |
| `how-ai-reads-docs.md` | Interactive retrieval demo page (`/how-ai-reads-docs/`) |
| `assets/js/retrieval-demo.js` | BM25 retrieval demo engine and UI, plus the live home page teaser (`data-rd-teaser`); sample docs and questions live in `retrieval-demo-data.js` |
| `scripts/export-excalidraw-svg.mjs` | Excalidraw → SVG export script (Playwright + esbuild) |

### Excalidraw Diagrams

Portfolio diagrams are authored as `.excalidraw` files in `assets/excalidraw/` and exported to SVG for display. Workflow:

1. Edit `.excalidraw` files in VS Code (using the Excalidraw extension)
2. Run `npm run export-svg` to re-export all SVGs
3. SVGs are referenced in portfolio markdown as `<img>` tags

Diagrams use Helvetica font (fontFamily: 2), no roughness, and a consistent color palette:
- Warm near-black (`#1c1008`) — category headings, card labels
- Amber (`#b45309`) — container borders, card borders, arrow strokes
- Warm cream mid (`#faebd7`) — category container fills
- White (`#FFFFFF`) — card fills
- Warm cream bg (`#fdf6ee`) — canvas background
